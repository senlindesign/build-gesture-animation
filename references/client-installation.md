# Client Installation

The source package follows the Agent Skills directory convention: one folder
containing `SKILL.md` plus optional scripts, references, assets, and client
metadata. Only the installation location changes.

| Target | Personal location | Project location |
|---|---|---|
| Codex | `~/.codex/skills/build-gesture-animation` | `.agents/skills/build-gesture-animation` |
| Claude Code | `~/.claude/skills/build-gesture-animation` | `.agents/skills/build-gesture-animation` |
| Cursor | `~/.cursor/skills/build-gesture-animation` | `.agents/skills/build-gesture-animation` |
| GitHub Copilot | `~/.copilot/skills/build-gesture-animation` | `.github/skills/build-gesture-animation` |
| Generic Agent Skills client | n/a | `.agents/skills/build-gesture-animation` |

Run from the source skill directory:

```bash
python3 scripts/install_skill.py --target codex
python3 scripts/install_skill.py --target claude
python3 scripts/install_skill.py --target cursor
python3 scripts/install_skill.py --target copilot
python3 scripts/install_skill.py --target agents-project --project-root /path/to/project
```

Installation copies the complete package and excludes generated bytecode. It
refuses to replace an existing copy unless `--force` is supplied. Validate the
source before installation and validate the installed `SKILL.md` with the
client's available checker afterward.
